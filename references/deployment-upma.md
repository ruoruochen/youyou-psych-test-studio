# 国内目标的 Upma 静态部署

仅在用户要求部署、上线或更新线上测试时读取。本指南是本 Skill 自身的部署流程；输入是当前测试项目的成品，不依赖其他测试 Skill、旧项目、Downloads 或作者账号。

## 平台与授权

国内用户需要打开并转发的测试，默认优先评估上码 Upma 的正式 `.upma.site` 地址，不先改用 Sites 或 `workers.dev`。用户明确指定平台时遵循其选择；不能把代理浏览器能打开当作国内可访问的证据。

用户明确说“部署／上线”后，已授权为当前测试取得公开、免登录的正式网址，直接完成必要发布，不再重复聊天确认“是否公开免登录”。若最初用途确实不明确，只问一次用途；已有仅本人查看等访问要求时遵守原要求。发布授权不包含购买套餐、接受新的法律条款、删除或覆盖无关项目。

使用当前环境已经授权的浏览器能力。若有 `ego-browser`，优先读取其 Skill、运行 `ego-browser skill` 并遵循当前 CLI/API 指南；若不可用，说明原因后按环境规则使用其他可用浏览器工具，不猜测 API 或要求安装旧心理测试 Skill。复用同一任务浏览空间；登录、验证码、新法律条款等必须本人处理的环节交给用户，完成后恢复原空间。系统权限审批按环境流程处理，不另加重复口头确认。

## 先核对当前条件

官方入口：[主页](https://www.upma.cn/)、[文档](https://www.upma.cn/docs)、[定价](https://www.upma.cn/pricing)、[条款](https://www.upma.cn/legal/terms)。每次发布读取当前控制台与官方规则，确认免费额度、正式链接条件、超额处理、官方标识、子域名回收及内容限制。

以下只作为历史操作依据，不是当前承诺：2026-10-21 观察到 Free 为 **2 个项目、100MB 存储、每月 1GB 流量、单次上传 10MB**，无 SLA，子域名可能被收回。不能据此推断现在仍是同一额度，也不能把其他套餐的线路宣传套到 Free。

先查看现有项目及用量，再决定创建或更新：

- 新测试使用独立项目，不能为腾额度覆盖无关测试。
- 用户要求更新已有测试时，从当前项目的发布记录定位，复用它的项目 ID 与正式 URL，保留本地回退版本。
- 名额、存储或流量不足时，不自行删除旧项目、购买或升级套餐。继续核对能否在授权范围内更新目标项目、使用用户已有的其他可用托管或其他免费方案；仍受阻则说明准确缺口，保留成品。不要把预览链接或仅代理可达的网址冒充交付。
- Skill 中不保存真实账号、旧项目 ID、旧域名或登录现场。实际项目标识仅写入该测试自己的发布记录。

## 上传与发布

1. 确认当前 `site/index.html` 已完成题库、计分、报告与导出的相应验收，且是自包含成品。部署请求不会把缺资料的演示自动变成完整测评；已获授权发布演示时保留清晰演示标识。
2. 记录上传文件的 SHA-256。只在 `File / Zip` 入口上传当前项目的 **`site/index.html`**，不上传完整项目压缩包、研究笔记、验收答案、账号资料或工作目录。如果成品仍依赖未内嵌资源，先完成单文件打包并验收。
3. 新建时填写当前测试名称；更新时进入已定位的目标项目，核对名称和正式地址后再替换文件。
4. 若有“展示到探索广场／公开展示”之类的额外推广开关，默认关闭。这与发布正式网址是两项不同设置，不需要用户再次确认。
5. 提交前核对仍为可用的免费服务，再点击发布。记录界面实际返回的项目标识和正式 HTTPS `.upma.site` 地址，不能猜 slug 或把短时预览地址写成正式网址。

### 广场开关的实际核验

过去界面中该复选框曾默认勾选，且文字 `label` 的 `for` 关联曾无效。不要仅凭点击文字或界面提示判断已关闭：观察当前页面中真实 checkbox 的 `checked` 状态；必要时点击实际包裹 input 的可见 label，再核验 `checked=false`。选择器来自当前页面结构，不固化旧 CSS 类名或坐标，也不误关其他复选框。

### 发布超时的恢复

一次实际发布中，点击后的 10 秒等待超时，但发布可能已经成功。遇到等待超时先看当前页面、项目列表或该目标项目状态，查正式地址与最新版本，不立即重复点击或新建。若已成功继续验收；尚在进行则等待可观察状态变化；确认失败后才针对原因重试。更新也始终复用原项目 ID 与正式 URL。

## 正式网址验收

在返回的正式地址验证，不能仅用本地成品或控制台预览替代。

- 核对 HTTPS、测试名称、题数、人物／维度内容和本轮版本。可直接取得原文件时比较 SHA-256；若平台合法注入标识或脚本导致摘要不同，记录差异，不能宣称逐字节一致。
- 尽可能从本机发起**无代理、无 Cookie**的只读请求，记录时间、HTTP 状态与成品核对结果。只请求目标正式站点，无需向第三方 IP 查询服务发送网络信息。
- 一次直连 HTTP 200 只证明该设备和网络在该时刻请求成功；不能承诺全国、所有运营商或永久可达。未能直连实测就明确标为未验收，不能用代理结果补成“已通过”。
- 在 **320px 与 390px** 手机视口检查首页、选项、提交、报告和导出按钮，无横向溢出。实际点击完成一套作答、提交并生成结果，下载实际 PDF 与 PNG；检查中文、分数一致性、分页及海报尺寸，不能只看按钮存在。
- 保留托管方官方标识，不隐藏、移除或覆盖其 badge 来规避免费规则。若 badge 遮挡选项或按钮，调整自己的布局、底部留白或控件位置，再检查移动端；平台注入脚本造成冲突时按允许方式修复或换平台。
- 检查页面外部请求与平台注入脚本是否影响计分或导出。应用本地处理答案，不等于托管方没有普通访问日志。

## 发布记录与交付

在当前测试项目内保存发布记录，至少包括：正式 URL、平台、实际项目／版本标识、发布时间、上传文件摘要、当日核对的免费条件、浏览器功能验证、直连请求的设备／网络和范围、尚未验证的部分及必要证据路径。不得保存 token、Cookie、账号截图或个人作答到 Skill，也不把它们打包发布；验收使用合成答案，记录功能结论即可。

更新项目说明中的正式入口与实际部署状态，保留其他内容。交付可点击的正式地址，简述免费额度与验证范围。完成后按当前 Ego 指南关闭任务浏览空间，不遗留无关页面。
